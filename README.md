# Нерасчётная сверхзвуковая струя: маршевый метод Годунова

Расчёт плоской недорасширенной сверхзвуковой струи (p_j/p_a > 1), истекающей из сопла в покоящуюся среду. Используется маршевый метод Годунова: координата x вдоль струи играет роль времени, а потоки через грани ячеек находятся из точного решения стационарной задачи о распаде разрыва (косые скачки и волны Прандтля–Майера). Через распады заданы и граничные условия: на оси симметрии и на свободной границе струи, где p = p_a.

Код написан на GNU Octave. В MATLAB он без правок не запустится: в нём есть Octave-специфичный синтаксис, например `figure(1, 'Position', ...)`.

## Параметры

Параметры задаются в начале [src/main.m](src/main.m):

| Параметр | По умолчанию | Смысл                                           |
| -------- | ------------ | ----------------------------------------------- |
| `gamma`  | 1.4          | показатель адиабаты                             |
| `M`      | 2.0          | число Маха струи на срезе сопла                 |
| `npr`    | 2            | нерасчётность p_j/p_a                           |
| `N`      | 100          | число ячеек поперёк полуструи                   |
| `kappa`  | 0.8          | коэффициент запаса в условии на шаг dx          |
| `every`  | 1            | печатать каждый `every`-й шаг (0 — не печатать) |
| `w_noz`  | 0.01 м       | полуширина сопла на срезе                       |
| `x_len`  | 0.2 м        | длина расчётной области вдоль оси               |

Внутри расчёт идёт в безразмерных величинах: длины отнесены к `w_noz`, а p_a = 1 и ρ_j = 1.

## Результат

Во время счёта в консоль печатаются номер шага, x, dx и положение границы струи y_e. В конце строится поле числа Маха в верхней полуструе вместе с её границей.

Расчёт останавливается с ошибкой в трёх случаях:

- где-то в потоке u ≤ c, и маршевый метод становится неприменим;
- скачок отходит или в распаде возникает вакуум;
- при восстановлении параметров из потоков дискриминант оказывается отрицательным (запирание). Обычно это значит, что шаг слишком велик, и помогает уменьшить `kappa`.

## Ограничения

- Течение всюду должно оставаться сверхзвуковым (u > c). Маховское отражение, дозвуковые зоны и возвратные течения маршевым методом не считаются.
- Модель невязкая: смешение струи с окружающей средой и пограничные слои не описываются.
- Газ совершенный, γ = const.
